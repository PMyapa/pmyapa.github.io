Yaka Run

    Play Game

Yaka run is an endless runner game of cute little devil characters which based on sinhalese traditional devil masked dancers. Our Yaka run game is simple, you just have to run, collect gems and make sure to select best from characters which have unlocked for number of gems you have collected. Join Our adorable 3D endless runner game today and have fun with our little Devils. You will see the number of gems for unlock each character in the game and after you have collected enough gems characters will automatically unlocked. There is a limit for number of gems which you can collect continuously. After it reached to the limit you can't collect more gems until it automatically getting refreshed. This limit and refreshing time will be different from each character. You can control character by tilt and swipe screen controls.
